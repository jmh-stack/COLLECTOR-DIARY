# 컬렉팅 가계부 (Collector Ledger)

외부 API나 백엔드 연동 없이 브라우저 로컬 스토리지(LocalStorage)에서 100% 동작하는 순수 클라이언트 가계부 애플리케이션입니다.

## 특징
- **100% 로컬 연산**: 회당 착용 원가, 감가율, 회수율, 정산 계산은 브라우저 내에서 자바스크립트 수식으로 직접 계산됩니다.
- **API 키 불필요**: Gemini API, AI SDK, 외부 결제/인증 API를 일절 사용하지 않습니다.
- **데이터 로컬 격리**: 다른 사용자와 데이터가 공유되지 않으며, 사용자 본인의 브라우저 로컬 스토리지에만 보관됩니다.
- **오프라인 지원**: 인터넷 연결 없이도 가계부 기록 및 보관함 관리가 가능합니다.
